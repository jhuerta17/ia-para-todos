# Next Steps — After the Demo

> **DRAFT:** On-ramp from the demo sprint to real operations,
> 2026-10-30. Nothing here has started; day counts begin when the
> work actually begins.

## The handoff

The demo answers "what could this look like?" Everything below
answers "what do we do first for real?" in dependency order. Each
step names its exit signal; do not skip ahead.

## 1. Start real conversations (weeks 1–2)

- Contact 3–5 potential community hosts using the
  [outreach process](../operations/outreach-process.md) and the
  [first-contact template](../../templates/partnership-outreach.md).
- Interview ~10 prospective participants about needs, devices,
  availability, and skepticism.
- **Exit:** ≥1 host willing to explore a pilot + written needs
  summary. No evidenced interest → pause, not force.

## 2. Run the 90-day pilot (months 1–3)

- Follow [90-day-pilot.md](../roadmap/90-day-pilot.md): validate,
  deliver ~2 small workshops, evaluate with a written verdict.
- Track every cost with receipts
  ([budget template](../operations/budget-template.md)); collect
  anonymous feedback
  ([template](../../templates/workshop-feedback.md)).
- **Exit:** repeat / adjust / pause verdict with known cost per
  participant. A "pause" verdict is a successful outcome.

## 3. Decide the legal structure (only if the pilot says repeat)

- Compare fiscal sponsorship vs. independent formation in
  [formation-options.md](../nonprofit/formation-options.md) using
  real pilot costs — not before.
- If sponsored/formed: bank account, basic bookkeeping, donation
  path, grant calendar.
- **Exit:** signed sponsorship or filed entity, with rationale.

## 4. Turn the demo into operations

- Replace demo mode page by page with the live stores it
  anticipates (scheduling, impact reporting, supporter ledger).
- Point the tutor and triage at the verified Muse API endpoint and
  key ([setup](ai-setup.md)); add admin auth to triage and a spend
  cap before announcing widely.
- Convert waitlist interest into the first real course cohort only
  after in-person demand is proven.
- **Exit:** Plans tracker retired or re-scoped; milestones
  [M1–M7](../roadmap/milestones.md) become the tracking spine again.

## What stays parked until demand is proven

Outreach beyond the pilot hosts, youth programming, paid courses,
B2B training, multi-city licensing, and any fundraising beyond
marginal pilot costs. See the locked [scope](scope.md) and
[future initiatives](../roadmap/future-initiatives.md).
