# Budget Template

> **DRAFT:** Reusable template. Example figures below are invented planning assumptions, NOT actual expenses. No workshops have been held and no money tracked yet.

## How to use this template

1. Copy the per-workshop table for each event.
2. Fill **Assumed** before the event (planning) and **Actual** after (receipts).
3. Compute cost per participant: total actual ÷ attendance headcount.
4. Keep receipts and this log **outside the public repository**; commit only aggregate learnings (e.g., "printing averaged $X/participant over 3 pilots").

## Rules

- Free to participants, always: no fees, no required purchases, no paid tools in curricula.
- Every expense needs a receipt and a category; estimates are labeled as estimates.
- Before handling donated funds: separate accounts and dual authorization (see `../nonprofit/` — planned).
- Financial details stay private; this repo holds only the template and anonymized aggregates.
